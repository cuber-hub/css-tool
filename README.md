#⚡ CSS Generator Hub

A lightweight front-end tool that helps developers generate ready-to-use CSS (and matching HTML snippets) with live preview.

## Features

- Gradient Generator
- Box Shadow Generator
- Border Radius Generator
- Flexbox Generator
- CSS Grid Generator
- CSS Animation Generator
- CSS Button Generator
- Glassmorphism Generator
- Clip-path Generator
- Loader / Spinner Generator
- Live preview for every tool
- Separate **Copy HTML** and **Copy CSS** buttons
- Dark/Light mode toggle
- LocalStorage support (remembers last values)

## Project Structure

```text
css tools/
├─ index.html
├─ css/
│  └─ style.css
└─ js/
   └─ main.js
```

## How to Run

This is a static project, so no build step is required.

1. Download or clone the project.
2. Open `index.html` directly in your browser.

Optional (recommended): run with a local static server for smoother development.

## How to Use

1. Open any generator from the sidebar or home cards.
2. Adjust controls (sliders, colors, selects, presets).
3. Watch the live preview update instantly.
4. Use:
   - `Copy HTML` to copy only HTML snippet
   - `Copy CSS` to copy only CSS code
5. Paste into your project and customize as needed.

## Tools contain

## Customization

- Update colors, spacing, and theme tokens in `css/style.css`.
- Add or modify generator logic in `js/main.js`.
- Adjust page sections and UI blocks in `index.html`.

## Browser Support

Works in all modern browsers (Chrome, Edge, Firefox, Safari).
